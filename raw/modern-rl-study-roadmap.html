动手任务

零安装：直接打开课程的 ModelScope 在线创空间，用 PPO 训练 CartPole（CPU 约 30–60 秒），看奖励曲线从 ~20 爬到 500，再看策略回放。

通关检查

能指着曲线说清：episode、reward、policy 各是什么？为什么起点在 20 附近、500 分意味着什么？（PPO 原理先不懂，没关系。）

动手任务

完成 3.3 价值函数数值实验；在格子世界里分别用 MC 和 TD 估计 V，亲手改一次折扣因子 γ，看价值估计怎么变。

合上讲义默写出 Bellman 期望方程；说清 MC 与 TD 如何估计价值、各自偏差/方差的区别；解释探索-利用困境。

动手任务

按顺序复现：DQN 解 LunarLander → 从零写 REINFORCE 解 CartPole → 跑通 PPO 长程任务；每个实验至少改一个超参（学习率 / γ / clip 范围）观察曲线。

通关检查

不看资料写出 REINFORCE；说清 replay buffer 和 target network 各解决 DQN 的什么问题；PPO clip 在防止什么；GAE 的 λ 在平衡什么。

四条防放弃原则

  1. 这是实验手册，不是小说。每章"通关"标准 = 导读问题答得出 + 实验跑通 + 改过一个变量，而非"看完"。
  2. 附录 D 数学不要先读。推导卡住时再按节查（概率期望 → D.2，梯度 → D.3，KL/熵 → D.4）。
  3. 允许跳读和二刷。Stage 3 可整体延后；很多内容在 Stage 4 第二次遇到时才会真正懂。
  4. 同一卡点超过 40 分钟就求助。顺序：重跑实验 → 对照附录 B 实现 → 把报错和你的猜测发我，我带你定位。
